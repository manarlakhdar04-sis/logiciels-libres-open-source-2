
# Applications Python - Analyse des données agronomiques

## Présentation du projet

Ce projet regroupe 12 applications Python réalisées dans le cadre du module **Logiciels Libres et Open Sources 2**.

Ces applications permettent d'explorer, analyser, visualiser et interpréter des données agronomiques et environnementales à l'aide de plusieurs bibliothèques Python.

## Applications disponibles

### 01 - NumPy
- Application 01-NumPy.py
- Application 01-NumPy-Interactive PRO.py
- Application 01-NumPy-Interactive PRO-01.py
- Application 01-NumPy-Interactive PRO-02.py

### 02 - Pandas
- Application 02-Pandas.py
- Application 02-Pandas-Interactive PRO.py
- Application 02-Pandas-Interactive PRO-01.py
- Application 02-Pandas-Interactive PRO-02.py

### 03 - Seaborn
- Application 03-Seaborn.py

### 04 - Dashboards
- Application 04-Dashboard_Analyse_Multvariee.py
- Application 04-Dashboard_Interactif.py
- Application 04-Dashboard_Interactif_Temperature.py

## Bibliothèques utilisées

- NumPy
- Pandas
- Matplotlib
- Seaborn
- Tkinter
- OpenPyXL

## Fichier de données

Le projet contient le fichier Excel :

`OPEN SOURCE DATA FILE.xlsx`

Ce fichier est utilisé comme source de données par les applications concernées.

## Environnement de développement

- Python
- Anaconda
- Spyder

## Exécution

1. Installer Python ou Anaconda.
2. Installer les bibliothèques nécessaires.
3. Ouvrir le fichier Python dans Spyder.
4. Vérifier la présence du fichier Excel requis.
5. Exécuter l'application.

## Objectif pédagogique

Mettre en pratique les bibliothèques Python dans l'analyse statistique, la visualisation des données et l'étude des phénomènes agronomiques et environnementaux.
